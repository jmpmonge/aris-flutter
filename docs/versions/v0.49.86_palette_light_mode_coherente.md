# v0.49.86 — Paleta clara coherente con modo oscuro

> Especificación original titulada **v0.49.40**. El tag `v0.49.40` ya existía en el repositorio (botonera perfil + cabecera fecha); esta versión publica la paleta clara como **v0.49.86**.

## Objetivo

Actualizar únicamente la paleta del **modo claro** para alinearla con la estética del modo oscuro aprobado: fondo frío, tarjetas blancas, azul Aris como acento principal, sin beige dominante. El modo oscuro no se ha modificado.

## Paleta aplicada (modo claro)

| Grupo | Tokens |
|-------|--------|
| Base | `#F5F7FB` fondo, `#FFFFFF` superficie, `#F8FAFD` / `#F1F5FA` elevados, `#D9E2EE` / `#E4EBF3` bordes |
| Texto | `#142033` primario, `#5E6B7D` secundario, `#8A97A8` muted |
| Marca | `#79AFFF` / `#5E97F6` / `#2D5FA8` / `#EAF2FF` / `#DCEBFF` |
| Home | timeline `#D7E4F5`, puntos `#6EA8FF`, clima `#E4B949` |
| Calendario | títulos azul carbón, celdas `#DCE5F0`, selección `#DCEBFF` + `#8BB8FF` + `#2D5FA8` |
| Tareas | sección `#6C9EF5`, tarjetas blancas, check `#79AFFF` |
| Notas | sección `#7CCB9A`, tarjetas blancas |
| Perfil | vía `ColorScheme` + tokens `profile*` en `AppColors` |
| Nav / FAB | `#DCE7FB` selección, `#6E98D8` FAB |

## Arquitectura

- `AppColors` + `lightScheme`: tokens base y `ThemeData` claro.
- `ArisListPalette` (`ThemeExtension`): colores de listas Calendario / Tareas / Notas por tema (`context.arisList`).
- `HomeCardTheme`: rama clara con bordes y textos fríos.
- Pantallas consumen tokens o `context.arisList`; colores hardcodeados del modo claro sustituidos.

## Pantallas revisadas

- **Inicio:** `today_summary_card.dart`, `home_live_header.dart`, `home_card_theme.dart`
- **Calendario:** `calendar_screen.dart`, vistas día/semana/mes, tarjetas y `event_detail_sheet.dart`
- **Tareas:** `tasks_screen.dart`, `task_expanded_card.dart`, `compact_expandable_task_tile.dart`, `manual_task_editor_page.dart`
- **Notas:** `notes_screen.dart`, `note_list_card.dart`
- **Perfil:** sin cambios directos (usa `Theme.of(context)` / `AppCard` ya alimentados por tema claro)

## Modo oscuro

**Confirmación explícita:** `darkScheme`, tokens `*Dark`, `ArisListPalette.dark` y constantes oscuras (`noteWide*`, `calendarList*`, etc.) permanecen intactos. Solo se actualizó la rama `light` / `Brightness.light`.
