# v0.49.78 — Cierre frontend · Premium press definitivo

## Objetivo

Cerrar la línea **v0.49.x** del cliente Flutter como versión **definitiva de frontend** (congelada). Refinar el micropress de Home hasta una respuesta material sobria y premium.

## Problema visual detectado

Tras v0.49.77, el overlay de press en Home:
- tapaba títulos con flash blanco;
- en modo oscuro el tinte era demasiado fuerte (alpha 0.48);
- la escala 0.985 y 110 ms se sentían bruscas o llamativas.

## Solución aplicada

### Premium press (Home y `PremiumPressable`)

| Parámetro | Valor |
|-----------|-------|
| Escala | **0.99** |
| Duración | **155 ms** · `easeOutCubic` |
| Tinte accent (claro) | **0.055** |
| Tinte neutral (claro) | **0.045** |
| Tinte oscuro | **0.18** |

- Tinte **detrás** del texto (nunca encima).
- Dos familias: **accent** (cabeceras) y **neutral** (filas secundarias).
- Sin ripple, rebote, glow ni destello.

### Limpieza

- Eliminado `home_preview_screen.dart` (pantalla de validación DS, no usada en producción).

## Estado del producto (cierre frontend)
