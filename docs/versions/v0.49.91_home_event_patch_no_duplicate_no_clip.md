## Problemas corregidos

### 1. Información duplicada en la ficha

**Antes:** la ficha usaba `CalendarDayEventExpandedContent`, que repetía ubicación/subtítulo ya visible en la fila (p. ej. «Café Central (mock)» + «Editar»).

**Después:** `_HomeEventExpandedDetail` muestra solo datos **adicionales** respecto a la fila compacta:

- descripción (si no coincide con el subtítulo);
- ubicación (si no coincide);
- participantes;
- duración;
- aviso/recordatorio;
- botón «Editar».

Si no hay extras → solo «Editar».

No se importa ni usa la tarjeta del Calendario Día.

### 2. Recorte de NOTAS al abrir la ficha

**Causa:** al crecer HOY, `_guardArisVisibleInViewport()` incrementaba `_layoutTightenSteps`, reduciendo `maxNoteItems` / `maxTaskItems` vía `HomeVisibleCounts.tightened()`.

**Corrección mínima:**

- `TodaySummaryCardState.hasExpandedHomeEvent` + callback `onHomeEventExpandChanged`;
- mientras hay ficha abierta: no aplicar tighten; resetear pasos al abrir;
- padding inferior del scroll solo cuando la ficha está abierta (`input + nav + safe area + 16`), sin cambiar el Home cerrado.
