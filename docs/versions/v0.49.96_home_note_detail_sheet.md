# v0.49.96 — Ficha flotante de nota al pulsar (Home y Notas)

## Objetivo

Mismo patrón que eventos (v0.49.93): al pulsar una nota se abre un **bottom sheet** con detalle completo, sin alterar el layout del Home.

## Comportamiento

1. Pulsar nota en **Home** o en **Notas** → `NoteDetailSheet`.
2. Muestra: icono, título, cuerpo completo, hora, carpeta, adjuntos, checklist, etiquetas.
3. **Editar** cierra la ficha y abre `ManualNoteCanvasSheet`.

## Mocks enriquecidos

`MockNotes.recent()` con cuerpos largos, etiquetas, hora, carpeta, adjuntos y checklist.

`HybridNoteRepository` superpone notas demo aunque haya backend (como calendario v0.49.95).
