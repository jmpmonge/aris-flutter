# v0.49.88 — Despliegue de eventos del Home con tarjeta del Día

## Objetivo

Permitir desplegar eventos del bloque **HOY** en Home con la misma tarjeta, animación y detalle que la vista Día del Calendario.

## Componente reutilizado

- **`CalendarDayEventCard`** (`lib/features/calendar/presentation/widgets/calendar_day_event_card.dart`)
  - Incluye `SmoothCardExpandReveal` + `CalendarDayEventExpandedContent`
  - Mismo comportamiento que en Calendario Día (`animateSize: false`)

## Adaptador

- **`HomeEventTimelineRow`** — fila HOY con hora, punto de timeline y `CalendarDayEventCard` (sin duplicar diseño).

## Archivos modificados

- `lib/shared/widgets/today_summary_card.dart` — estado `_expandedHomeEventId`, toggle, editor vía `EventDetailSheet`
- `lib/features/home/presentation/widgets/home_event_timeline_row.dart` *(nuevo)*

## Comportamiento

1. Pulsar un evento → `_expandedHomeEventId = event.id` → tarjeta desplegada.
2. Pulsar de nuevo → colapsa.
3. Pulsar otro → cierra el anterior y abre el nuevo (un solo evento expandido).
4. Integrado en el bloque HOY (sin modal ni navegación).
5. Línea vertical de timeline visible solo con todas las filas compactas; se oculta al expandir para no desalinear.

## Vista Día

**Sin cambios** en `calendar_day_view.dart` ni en `CalendarDayEventCard`.
