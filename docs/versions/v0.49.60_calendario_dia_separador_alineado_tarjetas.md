# v0.49.60 — Alineación del separador libre con tarjetas en Calendario Día

## Objetivo

Colocar el separador de huecos libres en el ancho de las tarjetas (no en toda la pantalla) y centrarlo verticalmente entre eventos consecutivos.

## Problema visual detectado

Tras v0.49.59, `CalendarFreeGapDivider` ocupaba el ancho completo del `Column`, quedando centrado respecto a la pantalla e ignorando las columnas de hora y timeline.

## Solución aplicada

Nuevo `_TimelineGapRow` en `calendar_day_view.dart`:

```
[hora vacía] [timeline spine] [──── 3 h ────]
```

- Misma estructura horizontal que `_TimelineEventRow` (columna hora + timeline + `Expanded` con `calendarDayTimelineContentGap`).
- `SizedBox` + `Center` para centrado vertical del separador en la zona de hueco.
- `calendarDayFreeGapMinHeight = 22` para huecos ≥ 45 min.
- Padding vertical del divider movido al contenedor; el widget solo renderiza líneas + texto.
- Eliminado `bottom` padding de filas de evento; el espaciado lo define `_TimelineGapRow`.
