# v0.49.65 — Mock de aviso y observaciones en tarjeta expandida Calendario Día

## Objetivo

Añadir datos mock controlados para validar visualmente ubicación, aviso y observaciones en la tarjeta expandida de la vista Día, antes de conexión real con backend.

## Problema visual detectado

Tras v0.49.64 la tarjeta expandida estaba preparada para mostrar detalles útiles, pero sin datos reales ni mock en esos campos la ficha quedaba demasiado vacía para revisar el diseño.

## Solución aplicada

**Opción A — mock en datos de ejemplo** (`MockEvents.daySchedule`):

Evento «Café con Laura» enriquecido con:

| Campo | Valor |
|-------|-------|
| `location` | Café Central |
| `reminderMinutesBefore` | 15 |
| `description` | Llevar documentación |

La tarjeta expandida ya leía estos campos vía `CalendarEventFormat.expandedLocation()`, `expandedReminder()` y `expandedObservations()` — sin cambios de UI.

**Resultado expandido esperado:**

```
Café con Laura                    ˄
📍 Café Central
🔔 Aviso 15 min antes
📝 Llevar documentación
Editar
```

Sin texto «mock» en pantalla.

## Archivos modificados

- `lib/core/mock/mock_events.dart`

## Conservado

Backend, contratos GPT, Home, tarjeta colapsada (solo título), timeline, separadores, Semana/Mes sin cambios de lógica.

## Pruebas

```bash
flutter analyze
flutter run -d chrome
```

Vista Día → expandir «Café con Laura» → comprobar ubicación, aviso y observaciones.

## Resultado final

Diseño de tarjeta expandida validable con datos mock locales.

## Limitaciones

- **Mock temporal:** aviso y observaciones en el evento café son datos locales de demostración hasta que el backend exponga `reminder_minutes_before` y `description` reales.
- Solo el evento «Café con Laura» del día genérico incluye los tres campos; el resto de mocks no se enriqueció.
- `homeTodayHighlights` no se modificó (Home intacto).
