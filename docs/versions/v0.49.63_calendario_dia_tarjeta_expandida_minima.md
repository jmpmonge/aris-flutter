# v0.49.63 — Tarjeta expandida mínima en Calendario Día

## Objetivo

Simplificar la tarjeta expandida de evento para mostrar solo información útil, sin etiquetas administrativas ni fecha repetida.

## Problema visual detectado

Tras v0.49.62 la tarjeta seguía mostrando una línea compacta de fecha·hora y mezclaba ubicación/notas en un solo bloque. La fecha ya está en la cabecera del día y la hora en la columna izquierda; la ficha resultaba redundante.

## Solución aplicada

**Estructura mínima expandida:**

- Cabecera: icono + título + chevron
- Hora debajo del título (también expandida)
- Líneas opcionales con icono:
  - 📍 ubicación
  - 🔔 aviso (solo cuando exista en modelo)
  - 📝 observaciones
- Acción **Editar**

**Eliminado:** fecha, etiquetas «Evento/Fecha/Hora/Notas», línea `fecha · hora`, tabla de dos columnas.

**Helpers:** `CalendarEventFormat.expandedLocation()`, `expandedObservations()`, `expandedReminder()`.

## Archivos modificados

- `calendar_day_event_card.dart`
- `calendar_event_format.dart`
- `app_spacing.dart`

## Conservado

Tarjetas colapsadas (título + hora), separadores libres, timeline, Semana/Mes, sin botón Eliminar.

## Pruebas

```bash
flutter analyze
flutter run -d chrome
```

Comprobado: vista Día, expandir evento mock «Café con Laura» muestra hora + ubicación + Editar.

## Resultado final

Tarjeta expandida más baja, legible y premium.

## Limitaciones

- El aviso (`expandedReminder`) no tiene campo en `EventModel` aún; la línea no aparece hasta que exista dato.
- Eventos mock sin `location` usan `detail` como ubicación cuando no hay `description`.
