# v0.49.97 — Tareas abre ficha inferior compacta

## Objetivo

Unificar el patrón de detalle con Calendario (v0.49.93) y Notas (v0.49.96): al pulsar una tarea **no se expande la fila**; se abre un **bottom sheet** compacto.

## Motivo

Las expansiones inline en la lista movían filas, complicaban el scroll y rompían la coherencia visual de Aris.

## Comportamiento

| Acción | Resultado |
|--------|-----------|
| Pulsar fila | `TaskDetailSheet` |
| Pulsar checkbox | Completar / desmarcar (sin abrir ficha) |
| Completar en ficha | Cierra ficha + acción existente |
| Editar | Cierra ficha + `ManualTaskEditorPage` |
| Eliminar | Solo si hay backend; diálogo de confirmación |

## Contenido de la ficha

- Estado (Pendiente / Completada)
- Título
- Sección (HOY, PRÓXIMAS, SIN FECHA, COMPLETADAS)
- Fecha, hora, prioridad, etiquetas si existen
- Descripción si existe
- Acciones: Completar o Marcar pendiente · Editar · Eliminar

Padding más compacto que Calendario/Notas (`AppSpacing.md`).
