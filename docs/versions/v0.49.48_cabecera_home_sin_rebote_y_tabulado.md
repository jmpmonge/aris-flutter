# v0.49.48 — Cabecera Home sin rebote de tarjeta HOY y tabulado simétrico

## Objetivo

Eliminar el empujón final de la tarjeta HOY durante el colapso de la cabecera viva y alinear fecha/clima con el borde exterior de las tarjetas.

## Problema detectado

La tarjeta HOY sufría un pequeño rebote al final del colapso porque el layout cambiaba frame a frame:

- `bottomPadding` se interpolaba con `t` de forma independiente;
- `ClipRect` + `Align(heightFactor: 1 - t)` reducía físicamente la altura del saludo;
- el `Column` de cabecera cambiaba de altura durante la animación;
- al terminar el controller, el cambio de rama compacta provocaba un segundo reajuste junto con el padding del `ListView`.

## Causa probable

Animación visual y altura de layout no estaban sincronizadas: el saludo desaparecía reduciendo altura mientras el padding inferior y el del `ListView` se ajustaban en fases distintas.

## Decisión

Separar animación visual interna de la cabecera del espacio que empuja HOY, sincronizando ambos con el mismo progreso `t`:

| Elemento | Comportamiento |
|----------|----------------|
| Saludo | `Opacity` + `Transform.translate`; altura con `SizedBox` interpolada |
| Slot saludo | `lerpDouble(homeGreetingSlotHeight, 0, t)` — sin `heightFactor` |
| Padding cabecera | `lerpDouble(4, 8, t)` sincronizado |
| Padding ListView | `lerpDouble(6, 12, t)` vía `HomeGreetingSession.collapseProgress` |
| Clima | sube + escala 1.0→0.78, `easeInOutCubic`, 600 ms, sin rebote |
| Tabulado | izquierda y derecha = `homePageMarginH` (borde exterior tarjeta) |

Al llegar a `t = 1`, las medidas coinciden exactamente con la rama compacta: no hay salto al cambiar de estado.
