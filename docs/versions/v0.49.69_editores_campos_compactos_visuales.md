# v0.49.69 — Unificación visual de campos compactos en editores

## Objetivo

Ajustar únicamente el formato visual de los campos compactos en los editores de Tareas y Calendario (bottom sheet «Editar evento»), sin cambiar contenido, lógica, modelos, callbacks ni estructura funcional.

## Problema visual detectado

La fila fecha · hora · tercer control usaba chips tipo píldora (`borderRadius: 20`, fondo sin borde explícito), visualmente alejados de los campos de título y notas (`_textSurface` con `radiusMd`, borde sutil y superficie elevada).

En Tareas la bandera ya era solo icono; en Calendario el aviso podía quedar como icono aislado cuando no había alarma activa.

## Solución aplicada

Nuevo widget compartido **`EditorCompactMetaField`**: rectángulos redondeados alineados con `_textSurface`, altura fija, borde sutil, icono azul de acento y texto claro.

**Tokens en `AppSpacing`:** `editorMetaFieldHeight`, `editorMetaFieldIconSize`, `editorMetaFieldGap`, `editorMetaFieldPaddingH`.

**`ManualEditorTimeMetaChip`** delega en `EditorCompactMetaField` (icono reloj); mantiene parámetros opcionales de superficie/borde para compatibilidad con otros editores.

### Editor de Tareas

| Control | Comportamiento visual |
|---------|----------------------|
| Fecha | Icono calendario + etiqueta corta cuando hay fecha |
| Hora | Campo compacto con reloj + `HH:mm` |
| Bandera | **Solo icono**; marca importante/no importante; sin texto «Media», «Alta», etc. |

### Editor de Calendario (Editar evento)

| Control | Comportamiento visual |
|---------|----------------------|
| Fecha | Icono calendario + fecha corta |
| Hora | Campo compacto con reloj + hora |
| Alarma | Campana + texto corto (`15 min`, `1 h`, **`Sin aviso`**) — no bandera |

## Aclaración funcional

- No se modificaron modelos, guardado, pickers, callbacks ni disposición de campos.
- No se tocó la tarjeta expandida de Calendario Día, Home, notas, timeline ni vistas Semana/Mes.
- `manual_event_editor_page.dart` no se estilizó; solo sigue compilando vía defaults en `ManualEditorTimeMetaChip`.

## Archivos modificados

- `lib/shared/widgets/editor_compact_meta_field.dart` — **nuevo**
- `lib/shared/widgets/manual_editor_time_meta_chip.dart` — delegación al campo compacto
- `lib/features/tasks/presentation/manual_task_editor_page.dart` — `_metaField` con `EditorCompactMetaField`
- `lib/features/calendar/presentation/widgets/event_detail_sheet.dart` — `_metaField`; alarma con «Sin aviso»
- `lib/theme/app_spacing.dart` — tokens de altura/gap/padding

## Pruebas realizadas

- `flutter analyze` — sin issues.

## Resultado final

Fecha, hora y tercer control se perciben como campos compactos de formulario (misma altura, radio `radiusMd`, borde y superficie), no como chips flotantes tipo píldora.

## Limitaciones

- La fila meta no se expande a ancho completo por control; mantiene `Row` con `mainAxisSize: min` como antes.
- El editor manual de evento legacy (`manual_event_editor_page.dart`) hereda el nuevo estilo del chip de hora solo si se abre; fuera del alcance explícito de esta versión.
