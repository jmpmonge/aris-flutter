# v0.49.59 — Centrado visual del separador de huecos libres en Calendario Día

## Objetivo

Mejorar el acabado del separador de huecos libres: centrado vertical entre tarjetas, líneas visibles a ambos lados y duración más legible.

## Problema visual detectado

Tras v0.49.57–58, los textos «3 h» / «5 h» quedaban muy tenues y el separador parecía una división de fondo, no un elemento intencional centrado entre eventos.

## Solución aplicada

Refinamiento de `CalendarFreeGapDivider`:

- `Row` con `CrossAxisAlignment.center` y líneas alineadas al centro del texto;
- padding vertical 4 px por lado (8 px total);
- padding horizontal del texto 10 px;
- opacidad línea 0.34, texto 0.58;
- tipografía 10.5 px.

Tokens en `app_spacing.dart`:

- `calendarDayFreeGapPaddingV`
- `calendarDayFreeGapTextPaddingH`
- `calendarDayFreeGapLineOpacity`
- `calendarDayFreeGapTextOpacity`

## Archivos modificados

- `calendar_free_gap_divider.dart`
- `app_spacing.dart`

## Conservado

Tarjetas v0.49.58, `gapDuration()`, Semana/Mes, Home sin cambios.

## Pruebas

```bash
flutter analyze
flutter run -d chrome
```

## Resultado final

Separador `──── 3 h ────` centrado, discreto pero legible.
